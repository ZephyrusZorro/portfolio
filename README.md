# FARIS. — Personal Engineering Portfolio

Ultra-modern, editorial technical portfolio website built for **Faris Ruknuddin** — SaaS Builder, Backend Architect, and AI Specialist.

> **"I architect scalable backends, engineer custom SaaS platforms, and orchestrate complex AI workflows from scratch."**

---

## 🛠 Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Space Grotesk, Inter, JetBrains Mono

---

## ✨ Features

- 🎨 **Swiss Editorial Aesthetic**: Minimal monochrome canvas (`#F7F6F0` / `#111111`) with subtle technical grid overlays.
- ⚡ **Living Architecture Visual**: Real-time interactive node diagram rendering system data flows (`INPUT` → `CONTEXT` → `LLM` → `ORCHESTRATION` → `AUTOMATION` → `OUTPUT`).
- 📁 **Engineering Bento Grid**: 9 featured projects with abstract SVG wireframe graphics and status badges (*Production*, *Pilot*, *Prototype*, *Winner*).
- 🔍 **Detailed Case Study Modals**: In-depth architectural breakdowns for every project (Problem, Approach, Architecture Pipeline, Implementation, Results, Lessons).
- 🌓 **Dark Mode**: System-aware theme toggle with persistent state.
- ⏱ **Live IST Clock**: Real-time India Standard Time indicator in footer.
- 🎯 **Desktop Custom Cursor**: Subtle monochrome pointer with dynamic `VIEW` card state.

## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/ZephyrusZorro/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.
